# DocAlign 网站使用说明

适用版本：DocAlign 0.1.0（2026-08-28 界面）

DocAlign 用于整理 Word 文档格式：先识别标题、正文、表格等结构，再按选定规则排版并验证。源文件不会被覆盖，处理完成后会生成新的 DOCX 文件。

## 一、打开网站

本地服务启动后，在浏览器访问：

<http://127.0.0.1:3000>

页面右上角显示“本地处理”时，文档、分析结果和输出文件均保存在本机。网站支持：

- 上传 `.docx` 文件，默认最大 20 MB；
- 粘贴纯文本并生成 Word 草稿；
- 结构分析、格式体检、自动排版和结果审计。

> “智能分析”和“自然语言编译”需要管理员先配置兼容模型。未配置模型时，其余功能仍可正常使用。

## 二、最快使用流程

1. 上传 Word 文档，或粘贴纯文本生成草稿。
2. 点击“分析结构”。
3. 检查左侧识别出的标题、正文等角色，必要时手动修正。
4. 在右侧选择一个整理方案。
5. 如需先查看问题，点击“只做格式体检”。
6. 点击“自动排版并验证”。
7. 任务完成后，点击“下载格式化 DOCX”，并按需查看审计结果。

## 三、详细操作

### 1. 导入文档

有两种方式：

- **上传 Word**：把 `.docx` 拖入上传区，或点击“选择文件”。
- **粘贴纯文本**：点击“粘贴纯文本”，填写文件名和内容，再点击“生成 Word 草稿”。

粘贴纯文本时，每行会生成一个段落，还可以使用简单标记：

```text
# 文档标题
## 一级标题
这是正文内容。
- 这是列表项
```

导入后，中间区域会显示浏览器预览。此预览仅供快速检查，最终效果请以下载后的 Word 文件和审计结果为准。

### 2. 分析文档结构

- **分析结构**：推荐默认使用。它在本地确定性识别主标题、各级标题、正文、列表、图表题、参考文献等内容。
- **智能分析**：适合结构复杂或识别结果不理想的文档。点击后会出现确认提示；确认后，段落文字和格式摘要会发送到已配置的兼容模型端点，DOCX 文件、图片和密钥不会发送。

分析完成后，左侧“文档结构”会显示每段内容、位置编号、识别置信度和角色。
顶部的复核栏会统计真正需要人工判断的段落；空段落不会计入待确认数量。文档较长时，可点击
“仅看待确认”快速聚焦。

### 3. 检查和修正文档角色

检查左侧每一段的角色，例如“主标题”“一级标题”“正文”“列表项”或“参考文献条目”。如果识别不正确，直接在该段右侧的下拉框中选择正确角色，系统会立即保存修正。

建议重点检查：

- 主标题和各级标题是否对应正确；
- 摘要、关键词、图题、表题是否被正确识别；
- “待确认”段落是否需要改为正文或其他角色；
- 参考文献和附录是否被正确区分。

### 4. 选择格式规则

#### 默认整理模式

适合大多数用户，不需要配置模型。系统会根据分析结果标出推荐方案，也可以手动切换：

| 整理方案 | 适用场景 | 主要特点 |
| --- | --- | --- |
| 常规文档 | 通知、论文、普通报告 | A4 竖版、正文小四、1.5 倍行距 |
| 紧凑信息 | 简历、会议纪要、操作手册 | 较紧凑、左对齐、节省页面空间 |
| 合同条款 | 合同和条款型文档 | 条款标题左对齐，保持连续阅读 |
| 宽表优先 | 财务报表、多列表格 | 保留必要横版分节，自适应表格宽度和字号 |

所有方案都会统一可见文字颜色、清除高亮和底纹，并启用内容保护与结果验证。

方案列表下方会显示“规则来源与适用边界”，包括规则包版本、维护方、复核日期、能力覆盖和已知
限制。当前四个内置方案都属于“通用方案 · 非机构合规”，不能替代 GB/T 9704、学校、期刊或
单位内部的正式模板。点击“查看覆盖范围与限制”后再决定是否适合当前文档。

#### 自然语言编译

需要先完成结构分析，并且管理员已配置兼容模型。

1. 切换到“自然语言编译”。
2. 输入要求，例如：“全文中文宋体，英文 Times New Roman；正文小四、1.5 倍行距；一级标题黑体三号居中。”
3. 选择是否启用“智能排版设计体系”：
   - 勾选：先设置完整的页面、标题、正文、列表和题注体系，再用你的要求覆盖对应部分；
   - 不勾选：只处理明确写出的要求，未提及的格式尽量保持原样。
4. 点击“编译为结构化规则”。
5. 查看“规则能力覆盖报告”，尤其留意“需要确认”和“当前无法执行”的内容。

自然语言编译只发送格式要求和精简的结构统计，不发送完整 DOCX 文件。

#### 自动结构排版

默认开启。系统会识别各级标题，并按手动换行或完整句子边界安全拆分过长正文。包含图片、公式、字段、书签等受保护结构的段落不会被自动拆分。

如果只想调整格式、不想重构正文段落，可以取消勾选。此时主按钮会显示“格式化并验证”。

#### 高级规则 JSON

仅建议熟悉 `FormattingSpec v1` 的用户使用。展开“高级规则 JSON”后可以精确修改规则；如果 JSON 的逗号、引号或括号有误，提交时会提示解析失败。

### 5. 先做格式体检（可选）

点击“只做格式体检”后，系统会按当前规则检查源文档，但不会修改文件，也不会创建格式化任务。

结果会显示偏差数量和位置编号，例如：

- `p3`：正文中的第 3 个段落；
- `s1`：第 1 个分节；
- `t1.r2.c3.p1.r1`：第 1 个表格中第 2 行、第 3 列的具体文字位置。

页面最多展示前 12 项问题，完整结果可通过 API 获取。

### 6. 自动排版并验证

确认规则后，点击“自动排版并验证”（关闭自动结构排版时显示“格式化并验证”）。

系统会在本地后台执行排版，并在完成后重新打开生成的 DOCX，检查内容完整性和格式合规性。任务运行时可以刷新页面；再次打开网站后会自动恢复当前工作区和任务进度。

如果检测到未授权的内容变化或受保护结构被改动，系统会阻止输出，源文件仍保持不变。

### 7. 下载和复核结果

任务完成后，右侧会显示“输出已生成”。可以：

- 先查看“排版结果摘要”，确认格式验证和原文保护是否通过；
- 查看实际格式调整数量，以及页面版式、标题与段落、字体、表格、页眉页脚和视觉清理等改动分布；
- 如果仍有人工复核项，点击“查看待确认段落”直接返回对应内容；
- 点击“下载格式化 DOCX”获取新文件；
- 点击“查看审计”查看机器可读的审计结果；
- 点击顶部“导出格式画像”下载源文档的格式画像 JSON。

建议用 Microsoft Word 或其他兼容软件打开下载文件，重点检查分页、字体可用性、宽表和图片位置。浏览器中的预览属于“最佳努力预览”，不代表 Word 的像素级最终效果。

## 四、数据与隐私

- 上传文件、分析结果、规则、任务和输出默认保存在本机 `DOCALIGN_DATA_DIR`。
- 源 DOCX 不会被直接覆盖，排版结果始终生成新文件。
- 点击“删除本地文档”会删除当前文档及其分析、规则、任务和输出，且不可撤销。
- “智能分析”仅在用户确认后发送段落文字和格式摘要。
- “自然语言编译”只发送格式要求和精简结构统计。
- 密钥只由后端环境读取，不进入浏览器、SQLite 或审计日志。

## 五、常见问题

### 页面提示“无法连接本地排版服务”

确认 API 和网站都已启动，然后点击页面中的“重试连接”。还可以访问 <http://127.0.0.1:8000/api/v1/health> 检查 API；正常时会返回 `status: ok`。

### 按钮是灰色的

- “分析结构”需要先上传或创建文档；
- “智能分析”需要先配置兼容模型；
- “编译为结构化规则”需要先完成分析、填写自然语言要求并配置模型；
- 排版任务运行期间，体检和重复提交按钮会暂时禁用。

### 预览显示不完整或与 Word 不一致

这是浏览器预览能力的限制。请下载 DOCX，并以 Word 中的显示和审计结果为准。

### 上传失败

确认文件扩展名为 `.docx`、文件未损坏且没有超过页面显示的大小限制。旧版 `.doc` 文件需要先在 Word 中另存为 `.docx`。

### 排版或验证失败

根据页面提示检查规则冲突、表格格式或内容保护问题。自然语言规则可以重新编译，高级 JSON 应先检查语法。失败不会覆盖源文件。

## 六、设置页面

点击右上角“设置”可以查看：

- 当前 API 地址；
- 是否启用本地处理；
- 兼容模型是否已配置；
- 当前上传大小限制。

模型端点和密钥需要由管理员在项目根目录的 `.env` 中配置，并在修改后重启 API。
